# ``FlowingDayControls``

Build calm, desktop-grade SwiftUI interfaces from reusable controls and shared design semantics.

## Overview

FlowingDayControls provides focused controls, fields, selection components, status views, and layout primitives for macOS 13 and later. The module owns presentation and interaction behavior while your application owns state, persistence, localization, and business rules.

Start with <doc:GettingStarted>, then customize the shared environment values described in <doc:Theming>. See <doc:Accessibility> before shipping an interface that changes the default keyboard or assistive behavior.
